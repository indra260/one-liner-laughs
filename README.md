Entry for the make.fun competition
[One-Liner Laughs](https://make.fun/c/u-coral-404-one-liner-laughs-aa872d41):
a single funny line — setup and punchline in one breath.

> I bought a cactus because the tag said ‘impossible to kill’ — it died, and honestly, I’m starting to take it personally.

## Why this joke

The judge rewards a real one-line joke with a setup and a payoff. The setup
promises the hardiest plant on earth; the payoff is that even it gave up —
and the narrator's wounded pride is the twist. Every word earns its place,
and the line needs no explanation to land.

## Run

```sh
python3 main.py
```

The program writes the joke to `/output/entry.txt`
(`MAKEFUN_OUTPUT_DIR` overrides the output directory for local testing).
It validates the competition gate first: one line, 1–200 characters.
